CI / CD Learning Project

Welcome to My Jenkins CI/CD Project

This website is being used to learn CI/CD (Continuous Integration and Continuous Delivery). Whenever I push new code to GitHub, Jenkins automatically builds it and deploys it for me.

About This Project

This is a simple website created to learn Git, GitHub, Jenkins, and automated deployment.

Git

Git keeps track of every change I make, so I can go back to an older version at any time.

GitHub

GitHub stores my project online and notifies Jenkins whenever I push new commits.

Jenkins

Jenkins runs a pipeline that builds my files and deploys them automatically.

How the pipeline works

  1. Code: I edit the HTML, CSS and JavaScript files.
  2. Commit: I save the changes with Git.
  3. Push: I upload the commits to GitHub.
  4. Build: Jenkins detects the push and runs the build job.
  5. Deploy: Jenkins publishes the website automatically.
